# 带符号伪影空间测度：现有 23 组回顾性验证

> 日期：2026-08-09  
> 契约：`docs/contracts/C2_signed_artifact_measure_validation_v0.1.md`  
> 范围：现有配对数据只读回放；无新仿真、无 MAR 训练、无放置参数因果推断。  
> 总判定：**概念通过；正式 Agent 指标部分 NO-GO。**

## 1. 做了什么

对 23 组同尺寸、同 affine、0.2 mm 等体素的 `artifact_L4 - clean` 计算带符号空间测度。每组同时计算 `tau=0/0.1/0.2/0.3`，共 92 行。输出包括：

- 亮/暗负荷及亮暗平衡；
- 0–2、2–5、5–10、10–20 mm 距金属表面距离带的亮暗负荷和负荷密度；
- 亮/暗二阶空间矩的传播尺度、主轴、线性度和平面度；
- 亮暗主轴一致性。

运行读取约 33 GB 压缩输入，顺序处理耗时约 323 秒；修正后的磁盘映射版本实测 RAM 约 0.29–0.34 GB。

## 2. 人工真值验证

| 检查 | 结果 | 判定 |
|---|---:|---|
| 强度翻倍，负荷比 | 2.000 | 通过 |
| 0°线主轴误差 | 0.000° | 通过 |
| 30°线主轴误差 | 0.009° | 通过 |
| 等 L1 线与圆环的线性度差 | 0.998 | 通过 |
| 圆环线性度 | 0.000 | 通过 |

第一版单一三维各向异性会把平面圆环也视为各向异性，已在全量运行前拆为线性度、平面度和球形度。这说明人工真值闸门确实阻止了一次错误指标进入正式结果。

二阶矩仍存在已知退化：复杂多条纹可能共享相近低阶矩；因此它只能作为紧凑形貌摘要，不能替代原始差分场或方向谱。

## 3. 与既有强度指标的一致性

在 `tau=0` 时：

\[
\text{shell pos density}+\text{shell neg density}=\text{shell MAE}
\]

23 组 0–2 mm 结果与既有统一 shell MAE 的最大绝对差为 `7.95e-9`。这证明带符号测度不是另造一把不相容的尺，而是对现有 MAE 的严格亮暗分解，并扩展了空间信息。

## 4. 阈值稳定性

以下为相对 `tau=0` 的 23 例 Spearman 排序相关：

| 指标 | tau=0.1 | tau=0.2 | tau=0.3 |
|---|---:|---:|---:|
| 总负荷 | 0.992 | 0.963 | 0.849 |
| 亮传播尺度 | 0.958 | 0.888 | 0.794 |
| 亮线性度 | 0.931 | 0.903 | 0.883 |
| 暗传播尺度 | 0.318 | -0.163 | 0.253 |
| 暗线性度 | 0.271 | 0.069 | -0.015 |
| 亮暗主轴一致性 | 0.923 | 0.825 | 0.710 |

亮主轴随阈值变化的中位角差为 1.82°、2.86°、4.31°；暗主轴为 18.24°、18.78°、28.31°，最大可达 60.27°。

**判定：**亮伪影空间矩具有较好的候选稳定性；暗伪影形貌在当前数据与阈值条件下不稳定，不能冻结为 Agent 正式反馈。

## 5. 局部结构是否提供了全局指标没有的信息

提供了。case24 BLC 的历史 0° 与 30°案例在 `tau=0` 下：

- 0–20 mm 总负荷仅差约 `-0.08%`；
- 亮线性度从 `0.317` 降至 `0.177`；
- 该差异在四个阈值下方向一致。

这说明“总量几乎不变但形貌改变”能够被空间矩识别，正是全局 MAE/总量指标可能漏掉的信号。

该案例只证明指标有区分行为，不证明角度导致该变化：历史角度组存在骨占比、旋转支点和放置合法性混杂。

## 6. 发现的关键失败模式

### 6.1 全局总负荷被远场体积主导

10–20 mm 距离带占 0–20 mm 总负荷的中位比例：

- tau=0：68.6%；
- tau=0.1：63.8%；
- tau=0.2：60.8%；
- tau=0.3：54.6%。

这是因为外层体积远大于近层，而且差分存在远场正偏置。全局总负荷与 0–2 mm MAE 的 Spearman 相关仅 `rho=0.134`。因此，0–20 mm 总积分不能单独作为“伪影严重度主指标”。

### 6.2 暗分量缺少稳定噪声/背景基线

现有数据没有独立 clean-clean 重复来区分负差分、随机噪声和重建背景漂移。暗区幅度小于亮区，阈值变化会显著改变暗区的主轴和传播尺度。当前只能保留暗负荷的分距离描述，不能解释为稳定暗条纹形貌，更不能直接归因于某一物理机制。

### 6.3 坐标语义尚未完成

当前主轴位于 NIfTI 世界坐标。未映射至种植体轴、颊舌向、近远中向前，只能表述“方向发生变化”，不能表述临床方向。

## 7. 当前放行结论

### 可以进入 C2 下一版的内容

1. 唯一底层对象：`D = artifact - clean` 的亮/暗空间测度；
2. 分距离带的亮暗**负荷密度**，并保留原 0–2 mm MAE 作参照；
3. 亮分量的二阶矩、线性度和主轴，状态为“候选指标”；
4. “全局相近但局部/形貌改变”可以预定义为发现信号类型。

### 当前不得进入 Agent 正式反馈的内容

1. 0–20 mm 总负荷作为唯一严重度；
2. 暗主轴、暗线性度或亮暗共线性作为冻结指标；
3. 世界坐标主轴的临床方向解释；
4. 用历史角度组证明角度效应。
