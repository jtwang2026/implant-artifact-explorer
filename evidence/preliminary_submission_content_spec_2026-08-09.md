## 初赛冻结决定

以下内容不再留给后续工具自行选择：

1. 具体情境采用“总负荷近似不变、亮形貌重分布”的历史观察，并强制携带混杂限制；
2. 研究空白采用“完整同构研究当前未发现”的候选表述，不使用零研究或长期忽视叙事；
3. 首期固定 case24/FDI36、完整牙列代理、固定 CAD、Ti64 和三项位姿自由度；
4. 骨嵴采用轴心参考深度与四方向深度联合语义，机械动作使用轴向平移量；轴向数值合法域由四方向骨/牙/神经管约束的交集确定，初赛不虚构固定上下限；
5. 倾角候选域固定为 0–20°，首次候选 0°/10°/20°，方位使用局部近中/远中/颊/舌方向；
6. 指标采用 `(A_±, p_±)` 框架；阈值选择方法冻结，实际 `τ_±` 必须由 Ti64 背景/重复校准产生；缺少数字不是写作缺口，禁止猜值；
7. `U` 的生成规则和 1U/3U 分级冻结；各指标实际 `U` 由校准产生，未校准前不声称检出效应；
8. 骨占比在当前固定 CAD 放置问题中作为中介/解释量，主总效应不固定、不直接调整；
9. 初赛验证预算固定为三个缓存场景、零个新物理仿真；首次真实闭环仅作为后续计划，预算为一个新点加一个匹配基准；
10. 单个真实点只允许一次同输入技术重试；第二次仍失败即停止，不能改参数冒充重试；
11. 随机参照未来使用主种子 `20260809`，与 Agent 同信息、同合法域、同新点预算；仿真噪声种子另由 Ti64 校准契约冻结，不混用；
12. 当前小预算探索授权点数为 `0`；只有缓存和单点闭环依次通过后，才能另立 amendment；
13. Agent、MAR 和临床价值均按计划能力书写，不写成已完成；
14. 学长“回到去伪影”作为强制问题定义输入；指标归属为负责人预定义并批准、人机协作形式化/实现。

后续工具可以压缩、排版和核对引用，但无权自行改变上述选择。若校准或正式文献检索产生反证，只能追加 amendment，不得静默改写。

## 总锚点

> 在固定病例、牙位、种植体几何与材料以及 CBCT 仿真管线时，种植体相对局部解剖结构的放置位姿如何改变金属伪影的强度与空间分布？这些效应是否稳定超过数值误差与随机波动？在上游规律得到确认后，按规律构建的仿真配对数据能否改善 MAR 的伪影抑制与结构保真，并最终减少对诊断相关影像信息获取的干扰？

初赛只承诺定义和验证前半段的最小探索闭环；MAR 和医生诊断价值是后续验证层，不写成已完成结果。

## 1.1 真实问题或需求

### 必须包含的具体情境

- 回放历史配对 CBCT 仿真数据时，BLC 0° 与 30°标签案例的 0–20 mm 总伪影负荷只相差约 `-0.08%`，但亮伪影线性度由 `0.317` 降至 `0.177`。
- 蹊跷是：总量指标几乎认为二者相同，空间形貌指标却提示重分布；放置变化可能不仅影响“有多少”，还影响“去了哪里”。
- 必须紧跟限制：历史案例存在骨占比、旋转支点和位姿合法性混杂，只作为提出问题的回顾性观察，不作为角度因果效应证据；不得写“仅角度不同”。

### 可陈述背景

- CBCT 是种植位点横断面评估的重要三维影像方式，可提供骨量、神经管等诊断相关信息。
- 金属种植体伪影可能干扰邻近结构的评价，影响依具体诊断任务而异。
- 有监督 MAR 需要像素对齐的有/无伪影配对数据；真实临床精确配对难以获得。
- 物理仿真是构建配对数据的重要路径之一，但模拟—临床域差异可能损害下游泛化。

### 本栏落点

从“总量相近但形貌不同”引出放置位姿对强度与空间分布的影响，并接到仿真数据生成和 MAR；不从工程 warning、文献缺席或旧 S/V 铁律起笔。

### 禁止表述

- “CBCT 是所有阶段最常用的影像手段”；
- “金属伪影必然严重影响所有诊断和手术规划”；
- “临床普遍采用仿真配对数据”；
- “已有结果证明角度造成形貌变化”；
- “放置参数从未被研究”。

## 1.2 为什么尚未被结构化

### 可陈述事实

- 放置位置、角度和对象/受试者相对扫描器方位已有范围综述和原始研究，不能声称完全空白。
- 现有研究的操纵对象不统一：部分改变种植体相对解剖位姿，部分改变头部/模型相对扫描器方向；两者科学含义不同。
- 结局不统一：灰度、伪影面积、CNR、诊断任务等不能直接等价为强度与空间分布的统一测量。
- 本轮定向检索尚未发现与本项目完整同构的研究链：固定扫描和解剖、仅改变相对局部解剖位姿、联合测量强度与空间分布、再检验 MAR 数据价值。

### 未结构化的四个原因

1. **变量语义未统一**：implant-to-anatomy pose 与 object/head-to-scanner orientation 常被混称角度或位置；
2. **测量对象未统一**：标量严重度不能充分表达距离、方向和形貌重分布；
3. **证据链分离**：放置比较、物理仿真和 MAR 数据生成尚不能直接回答完整链条；
4. **成本约束**：连续三维位姿空间中的每个新点都需物理仿真，穷举成本高，适合有限预算序贯探索。

### 证据等级与禁语

- “完整同构研究当前未发现”只能写成定向检索后的候选判断；正式数据库检索完成前，不得写成已证明空白。
- 骨下深度只能写“本轮定向检索未见直接命中”，不能证明不存在。
- 禁止“只有零星两三个角度”“没有参数化研究”“领域长期将放置视为无需验证前提”等宽泛表述。

## 1.3 研究价值与合适切片

### 科学价值

- 检验放置位姿是否产生超过技术不确定性的强度变化、空间重分布、非线性、交互、反例或稳定负结果。
- 使用带符号误差分布分开“负荷强度”与“空间形貌”，避免总量相近时漏掉空间变化。
- 为仿真配对数据生成提供可检验依据：只有经确认影响伪影的数据维度，才有理由纳入下游数据策略。
- 稳定负结果也可缩小需要模拟的放置空间。

### Agent 角色

- 这是拟议能力，不是当前已完成成果。
- Agent 在有限预算下读取预定义摘要，登记可证伪假设，选择下一个合法位姿，接收反馈，以 `supported/refuted/insufficient` 判断并修正或停止。
- 固定物理管线负责模拟；人类负责问题、指标、门槛、预算和结论升级；Agent 不得改变科学定义或绕过审批。
- 启动时生成固定参数表再批量运行，不构成反馈驱动探索。

### 首期切片

- case24 / FDI36；完整牙列理想化虚拟金属插入代理域；
- 单病例、单牙位、固定 CAD、固定 Ti64、固定扫描与重建；
- 三个放置维度：轴向放置、相对基准轴的倾角幅度、局部解剖倾斜方向；
- 倾角候选域 `0–20°`，首次候选水平 `0°/10°/20°`；30°仅为另批边界测试；
- 深度采用轴心参考与近中/远中/颊/舌四方向联合语义，不使用无方向单标量；合法域待工程验收；
- 只回答固定理想化仿真域，不外推真实缺牙患者、临床安全或个体化治疗建议。

### 禁止表述

- “填补已被证明存在的空白”；
- “为临床个性化种植提供放置建议”；
- “Agent 已完成自主发现”；
- “单病例结果能够改善临床诊断”。

## 2.1 固定规则

### 环境身份与固定条件

- `case_id=YOFO_No_Metal_24`，`tooth_fdi=36`；完整 FDI36 牙体保留，种植体为理想化虚拟金属插入；逐点记录 `native_tooth_overlap_ratio`。
- 固定种植体 CAD、螺纹、直径、锥度、材料 Ti64 和绕轴滚转。
- 固定扫描、物理仿真、重建、随机策略和指标版本；任一固定项变化产生新 `environment_version`。

### 坐标与动作语义

- 世界坐标单位 mm；正式局部原点为平台中心；`e_z` 平台指向根尖，`e_x` 远中，`e_y=e_z×e_x` 为颊侧正方向。
- 轴向动作用机械平移量表达；每个位姿返回轴心参考与四方向深度。
- `tilt_deg` 表示相对基准 `e_z` 的倾角；`tilt_azimuth_deg` 表示局部方向；`tilt_deg=0` 时方位角必须为 `null`。
- 历史 `offset_mm` 不等于骨下深度；历史 `thread_depth_mm` 是螺纹径向深度，均不得复用为当前科学字段。

### 质量门控

- 参数/null、刚体矩阵、影像边界、骨/牙/神经管状态、四方向深度；
- mask 连通性、边界接触、mesh→mask 体积误差、仿真与指标可计算性；
- 状态仅 `pass/fail/unknown_due_to_missing_anatomy`；缺失解剖不得解释为安全；
- 质量失败可作为环境失败模式，不得解释为物理效应。

### 写作边界

- 以上是拟冻结环境定义，当前 C1 整体尚未工程验收。
- 不把旧 `0.10 mm` 几何校准口径写成当前新环境的固定评估口径；正式分辨率和配置以未来 manifest 为准。
- 不写 100 kVp、20-bin 等参数已形成完整冻结 manifest；只能说明已有物理管线，正式试跑前将版本化和哈希化。

## 2.2 观察 / 行动 / 反馈

### 观察

1. 环境、契约、代码、CAD、材料、仿真、重建、指标版本/哈希；
2. 当前预算、轮次、已完成/失败/待审批任务；
3. 已完成任务的三项放置动作、合法性和质量状态；
4. 主强度指标 `shell_mae_0_2`；
5. 亮负荷的分距离密度、传播尺度、线性度、平面度、质心偏移及主轴相对种植体轴夹角；
6. 暗负荷的 0–2/2–5/5–10 mm 辅助密度，不提供未通过校准的暗方向；
7. `bone_ratio`、骨接触和原生牙重叠等中介/解释量；
8. 不确定性包络或缺失原因；缺失值必须 `null + reason`。

### 行动

- `register_hypothesis`：登记依据、因素、对照、预测、证伪条件和竞争解释；
- `propose_experiment`：提出轴向放置、倾角和倾斜方向，并说明唯一改变因素、匹配对照、预期、预算和停止条件；
- `request_analysis`：调用预登记的描述、匹配、趋势、交互或不确定性分析；
- `judge_result`：仅提交 `supported/refuted/insufficient`；
- `revise_hypothesis/stop`：保留旧版本并记录触发证据。

Agent 不能直接运行未经合法性和预算审批的真实仿真，不能改变 CAD、材料、扫描、重建、指标或成功门槛。

### 反馈顺序

1. 合法性、重复性、预算和审批结果；
2. 任务状态及版本；
3. 质量门控；
4. 仅在质量通过后返回指标；
5. 与预指定对照的原始差异和不确定性；
6. 系统不替 Agent 生成科学结论，由 Agent 提交三态判断。

## 3.1 什么算发现

### 发现类型

- 稳定强度效应；非线性、平台、非单调或可辨识交互；
- 总量相近但距离、方向或形貌发生重分布；
- 反例和适用边界；有检出能力和等效界值下的稳定负结果；
- 数值、离散化、质量门控或测量失败模式；
- 后续 MAR 阶段的数据有效性信号。

### 量化规则

令 `U=max(技术重复差异, 实现/分辨率敏感性, 指标计算误差)`：

- `|Δ|≤U`：证据不足；
- `U<|Δ|<3U`：候选效应；
- `|Δ|≥3U`：强候选效应；
- 候选和强候选都须通过预留确认点或独立重复，才能成为确认信号；`3U` 不等于统计显著、因果或临床价值。

每个假设预先指定一个主终点。强度问题原则上使用 `shell_mae_0_2`；空间问题从亮负荷距离分布、传播尺度、线性度或轴向关系中预选。暗负荷只能辅助，暗形貌方向不能作为发现终点。

骨占比在当前固定 CAD 放置研究中作为中介/解释量，主总效应分析不固定也不直接调整；历史几何研究中可能是混杂，两种语境不得混写。

## 3.2 平凡解 / 随机 / 无干预

- **无干预参照**：C1 最终冻结的基准位姿；它是物理对照，不是最优答案。
- **简单固定设计**：预注册的单因素匹配扰动或小型均匀设计；不得按 Agent 结果临时挑点。
- **随机参照**：与 Agent 使用相同合法空间、信息、新点预算、质量门控、工具、审批和停止条件；初赛后续计划的主种子固定为 `20260809`。
- **可选人类启发式**：看不到 Agent 结果时预登记点位和理由，仅比较决策效率。

比较：质量通过比例、预测/证伪完整度、新点辨识贡献、共同预留点预测、确认成功率和假阳性、点数/时间/算力，以及反馈是否真实改变下一步。不能只比较谁找到的最大伪影更高；固定列表不算自适应探索。

## 3.3 最低成功与失败标准

### 控制流成功

- 支持、反驳和质量失败三个缓存场景均产生完整观察—行动—审批—反馈—判断—修订/停止链；
- 反驳或质量失败后不得机械重复原计划；
- 严格字段、版本、质量门控和日志恢复通过。

### 首次真实闭环成功

- 一个预登记可证伪假设；一个经审批新点及匹配基准；
- 质量报告和预定义 C2 指标回流；Agent 给出三态判断；
- 判断改变下一提案或触发停止；版本、证据和成本可复现。

这只证明闭环可运行，不等于发现规律或 Agent 优于参照。

### 明确失败

- Prompt 泄露答案；结果未回流或未改变下一步；只有排队无结果判断；
- 质量失败仍解释为物理效应；缺失字段被静默默认；
- 看到结果后改阈值、主终点或成功标准；参照预算/信息不等价；
- 单点升级为机制、因果、MAR 或临床获益；超预算、不可复现或日志无法还原。

失败保留为失败模式，据此收窄问题、修复环境或停止，不删除记录美化结果。

## 4.1 一次试跑怎么做

### 初赛最小试跑

目标：证明 Agent 能根据新反馈完成假设修正，不验证科学规律。

输入：三个标注为测试用途的缓存/合成场景，分别模拟支持、反驳和质量失败；冻结的观察 schema、动作 schema、质量门控和预算计数器。

步骤：读取环境与预算 → 登记假设/预测/证伪/竞争解释 → 提出结构化实验及匹配对照 → 合法性/重复/预算审批 → 返回缓存质量与指标 → 三态判断 → 修订、改变下一提案或停止 → 审计事件链和泄漏。

输出：三条追加式日志、schema 校验、Prompt 泄漏审计、预算记录和双重自检报告。

缓存结果不能作为科学证据。只有 P0–C4 全部冻结且负责人另批预算后，才进入“一个新点＋匹配基准”的真实闭环。

## 4.2 主要风险与失败路径

| 风险 | 识别 | 失败处理 |
|---|---|---|
| 文献空白过强 | 正式检索、反证台账 | 降级措辞或修正问题 |
| 骨嵴方向差异 | 四方向极差与敏感性 | 联合深度语义；不放宽 2 mm 闸门 |
| 完整牙列代理偏差 | 牙体重叠率 | 限定适用域，不外推真实缺牙 |
| 位姿非法/解剖缺失 | legality report | `fail/unknown`，不分析 |
| mesh/mask 离散误差 | 体积、连通、边界 | 质量失败，新版本修复 |
| 阈值不稳定 | clean-clean、敏感性 | 未冻结指标不进入 Agent |
| 远场体积主导 | 分距离密度 | 不用总积分作唯一严重度 |
| 埋骨率语义混乱 | 因果图、字段审计 | 当前作中介，不直接调整 |
| Agent 答案泄漏 | Prompt/工具审计 | 比较作废，从缓存阶段重启 |
| 参照不公平 | 信息/预算/评价集核对 | 比较作废；禁用历史 `+51.1%` |
| 结果不回流 | 事件链 | 不算闭环或 Agent 发现 |
| MAR/临床越级 | claim ledger | 降级证据层，另立契约 |

失败保留输入、版本、日志、质量报告、判断和成本；修复产生新版本，不覆盖失败证据。

## 4.3 复现与开源计划

### 数据与授权

- 记录病例、牙位、参考影像、分割、CAD 和授权来源；原始数据能否公开以原授权为准。
- 受限输入不发布；发布哈希、schema、生成说明、聚合统计和合成夹具，不伪造公开可用性。

### 环境与复现单元

- Python、数值库、TIGRE/物理仿真、重建接口和 RISE-MAR 版本化；
- 正式运行前生成 manifest：扫描谱、材料、噪声、重建、随机种子及代码/二进制/输入哈希；
- 发布规范动作 JSON、幂等键、质量报告、指标结果、事件日志、固定/随机种子和追溯矩阵；
- 缓存三场景可在无真实数据、无新仿真条件下复现控制流。

### 开源边界

不承诺开放：授权受限的原始 CBCT/分割、第三方不可再分发资产、密钥、患者可识别信息及许可不允许发布的二进制/权重。第三方组件保留原许可证和来源。
