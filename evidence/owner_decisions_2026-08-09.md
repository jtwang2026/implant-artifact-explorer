## 1. 负责人的"具体情境"（1.1 写作依据，负责人确认）

不是 offset 警告，也不是"文献没找到"，而是这个画面：

> 在回放已有配对 CBCT 数据时，两组标记为 BLC 0° 与 30° 的案例，旧的 0–20 mm 总伪影负荷只相差约 **−0.08%**，按单一总量指标几乎会被判断为"没有变化"；但亮伪影线性度从 **0.317 降到 0.177**，空间形貌明显重分布。也就是说，放置变化未必显著增加或减少伪影总量，却可能改变伪影传播的位置、方向和形状，而这些变化恰好可能影响邻近诊断相关结构，也可能被传统标量指标漏掉。

**主问题的"观察到蹊跷"**：为什么总强度几乎不变，空间形貌却明显改变？放置参数影响的可能不是"伪影有多少"，而是"伪影去了哪里"。

**证据边界（必须紧跟）**：历史角度案例存在骨占比、旋转支点和位姿合法性混杂，因此这里**只作为触发问题的回顾性观察，不作为"角度导致形貌变化"的因果证据**。

**该情境的自然引出链**：放置参数 → 强度与空间分布 → Agent 有限预算探索 → 数据生成策略 → MAR。不得把旧工程 warning、文献缺席或铁律硬塞进 1.1。

## 2. (A_±, p_±) 的执行定义（负责人确认）

### 2.1 阈值选择

正式新数据**不要按案例内分位数设阈值**（分位数随伪影变化，尺子跟着答案移动）。优先规则：

1. 使用 clean-clean 技术重复或无金属重复估计背景偏置 b 和技术噪声；
2. 令 D₀ = D − b；
3. 根据预注册的背景假阳性预算选择 τ₊、τ₋（例如背景区域阈值超限体素比例不超过预定值）；
4. 可用稳健尺度的 kσ 作为实现，k 在校准集上冻结，不在探索结果出现后调整；
5. 若正负噪声不对称，分别估计 τ₊ 和 τ₋。

**历史数据没有 clean-clean 重复，保持现有结论**：
- 亮分量保留多阈值敏感性结果，不追认唯一物理阈值；
- 暗负荷沿用已冻结的"10–20 mm 背景、MAD、k=3"辅助定义；
- **新 Ti64 数据必须重新校准，不能继承 CoCr 或历史数据阈值**。

### 2.2 参考坐标系

正式位姿数据统一使用：
- **原点**：种植体平台中心；
- **e_z**：平台指向根尖；
- **e_x**：远中方向；
- **e_y = e_z × e_x**：当前冻结定义中的颊侧正方向；
- **距离带**：距实际金属 mask 表面的欧氏距离，**不是**距平台原点的球半径。

不以金属质心或根尖作为正式原点（不能对应平台—骨嵴放置语义）。历史数据若缺 placement，只允许"mask 质心＋PCA 长轴"作为明确标注的回顾性 fallback，不得与正式局部解剖方向混写。

### 2.3 p_± 定义与 Agent 查询量

p_±(x) = μ_±(x)·ΔV / A_±；当 A_± = 0 时返回 **null + reason**，不得填零分布。

**Agent 不读取完整体素场**，读取预定义摘要：
- A₊、A₋：总负荷或指定距离域负荷；
- 距金属表面 0–2、2–5、5–10、10–20 mm 负荷密度/质量比例；
- p₊ 的局部质心偏移向量；
- p₊ 的二阶矩、RMS 传播尺度、线性度和平面度；
- p₊ 主轴与种植体轴的无向夹角；
- 局部坐标冻结并完成数据映射后，再报告近远中/颊舌分量。

**暗形貌未通过校准**：当前 p₋ 只给分距离暗负荷，不给暗质心、暗主轴或暗线性度。

## 3. 效应与误差带的数字规则（负责人确认，C4 推荐待冻结）

保留 1×/3× 框架，但**严格区分"强度标签"和"证据确认"**。

不确定性包络 U = max(技术重复差异, 实现/分辨率敏感性, 指标计算误差)。

预注册判定：
- |Δ| ≤ U：与误差不可区分，**insufficient**；
- U < |Δ| < 3U：**候选效应**；
- |Δ| ≥ 3U：**强候选效应**；
- **无论是否超过 3U，都必须通过预留确认点或独立重复，才能成为"确认信号"**。

因此：3U 只表示相对技术误差较大，**不等于**统计显著、独立确认或因果成立。

**多指标搜索**：预先指定主终点；不能在几十个指标中挑出超过 3U 的结果。**稳定负结果**必须另冻等效界值，不能由"未超过 U"推出。

这些倍数先写入 C4 为"推荐待冻结规则"，最终必须等 Ti64 的 U 校准完成后由负责人确认。

## 5. 埋骨率的处理（负责人确认：中介，不调整）

**主分析不固定埋骨率，也不作为普通协变量直接调整；将其作为放置参数作用后的中介量记录。**

理由：固定 CAD、材料和病例后，改变深度或倾角自然会改变骨内占比。骨占比很可能位于"放置参数 → 骨内关系 → 伪影"。直接调整骨占比会删掉放置效应的一部分机制；强行固定骨占比可能迫使改变其他几何量，破坏单因素设计。

具体处理：
- **主终点**：估计放置参数的总效应，不调整 bone_ratio；
- **合法性**：骨内占比、骨接触及四方向深度作为位姿合法性和解释量；
- **次级分析**：预注册中介/分层分析，检查效应是否随骨占比、骨接触或牙体重叠变化；
- 不得仅凭相关性写"骨占比导致伪影变化"；
- 若未来研究"排除骨接触后的直接效应"，**另立辨识实验**，不能用当前主分析顺手完成。

**两种语境必须分开**：历史螺纹几何实验中埋骨率可能是混杂；当前固定 CAD 放置研究中它更可能是中介。
