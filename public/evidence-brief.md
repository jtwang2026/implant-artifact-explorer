# 植位智探：Demo 证据简报

## 页面定位

这是历史科学探索环境回放 Demo。它展示“公开厂家规格与工程假设 → 参数化 CAD → 虚拟植入 → CBCT 物理仿真与重建 → 指标评估”的真实工程链，以及 Agent 已介入的螺纹深度 × 螺距选点。它不能作为当前“放置参数如何影响 CBCT 金属伪影”问题的验证结果。

## 环境可行性

- 参数化 CAD 生成器读取官方长度/直径与独立标注的工程假设，修改 `thread_depth_mm`、`thread_pitch_mm` 后生成 STL。
- `placement.json` 把 CAD 放入 case24/FDI36，体素化生成 metal mask。
- 固定物理管线输出 `artifact_L4.nii.gz` 与 `clean.nii.gz`；评估器计算 0–2 mm 壳层 MAE、S/V 和投影域摘要。
- 24 个历史任务均有 `result.json` 与 `quality_report.json`。24/24 的 mesh→mask 警告说明链路可运行，但科学结论仍需质量门控。

## Agent 当前介入边界

- 2026-08-03 的 5 个 Agent 新点和 2026-08-04 的 3 个 Agent 新点，均可对应到完成状态与 `result.json`。
- Agent 日志保存了点位与自由文本选择依据；部分理由包含预期偏离或阈值。
- 当时实现主要使用启动时静态摘要并批量排队，尚未形成新 C3 契约要求的“单点结果回流—三态判断—下一点修订”链。
- +51.1% 结果的口径核对、降级和撤回来自负责人/项目审计流程，不是 Agent 自主审查能力。

## 可追溯事实

- 历史受控几何数据：13 组。
- 历史探索任务：24 个；24/24 留有 mesh→mask 警告。
- 历史指标：S/V（几何复杂度）、0–2 mm 壳层 MAE（近场伪影强度）、相对材料基线的残差及新颖性。
- Agent 补入大螺纹深度 × 多螺距点后，历史高深度负残差信号仍为候选；depth 与旧 offset 共线，且数值警告未完全排除。
- 旧盲测中 Agent 覆盖 3 例、随机基线覆盖 5 例，原报告 +51.1% 改善不可比较，已判无效。
- 骨嵴校准显示方向差异不可忽略，单一标量深度未通过预注册闸门；当前采用“轴向参考 + 颊/舌/近中/远中四向深度”。
