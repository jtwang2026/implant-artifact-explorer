# 植位智探 · CBCT 伪影科学探索环境 Demo

**GOAI 世界人工智能开源大赛 · AI for Research 前沿探索赛道 · 开放探索赛题** · 初赛 Demo

> 科学问题：在固定病例与 CBCT 仿真条件下，种植体放置参数（深度、倾角、方向）如何影响金属伪影的强度与空间分布？确认后的规律能否指导仿真数据生成、改善 MAR 训练？

## 这是什么

一个**可审计、可证伪、可延续**的 Agent 科学探索环境的交互演示。共 5 个页面：

| 页面 | 内容 | 数据 |
|---|---|---|
| `/` 首页 | 问题定义 → 方法可行性 → 诚实披露 → 下一步 | 概览 |
| `/geometry` | 几何参数探索实验室：8 个 Agent 真实选点决策链重演 + 参数扫描器 | **真实历史仿真** |
| `/sim` | 仿真配对数据对比（滑杆/差分热图/剖面线/距离分布）+ 分层物理 L0–L4 | **真实重建**（z=240 金属主体切片） |
| `/kb` | 种植体参数溯源库：官方 vs 工程假设分离、证据分级、网格验证 | 真实知识库（SQLite 导出） |
| `/playground` | Agent 闭环体验器：缓存三场景（支持/反驳/质量失败） | 缓存/合成（不作科学证据） |

## 核心设计

- **真实数据优先**：几何探索、仿真重建、参数溯源全部来自已执行的真实工作，非虚构演示
- **分层物理可解释**：L0 单能 → L1 多能谱（束硬化）→ L2 光子饥饿 → L3 散射 → L4 MTF，每层差分可见
- **诚实贯穿**："+51.1% 盲测已撤回"、"24/24 网格警告留痕"、"当前 NO-GO"如实披露

## 本地运行

```bash
npm ci
npm run build
npm run start
# 访问 http://localhost:3000
```

需要 Node.js ≥ 22.13。

## 技术栈

- [vinext](https://www.npmjs.com/package/vinext)（Next.js on Vite）+ React 19 + TypeScript
- 数据：真实 NIfTI 重建切片（Python/matplotlib 提取）、SQLite 知识库（导出为静态 JSON）

## 科学边界（重要）

- 本 Demo 为**初赛材料**，展示的是"方法可行性 + 诚实证据链"
- 历史几何探索（螺纹深度 × 螺距）**不构成**当前放置参数问题的因果证据
- 当前真实放置探索状态为 **NO-GO**（P0–C4 契约未全部冻结）
- `/playground` 为缓存/合成演示，结果**不作为科学证据**
- 仿真配对数据展示的"层间视觉差异较小"是真实物理事实（伪影在重建域弱于视觉阈值），量化指标（shell MAE、暗区比例）用于科学判断

## 数据与合规

- 25 例真实 CBCT 为天池竞赛数据（仅限竞赛用途），**未包含**在 Demo 中
- 本 Demo 仅含仿真产物（可开源）与公开参数信息
- YOFO 重建 DLL 为商业闭源组件，本 Demo 不包含；仿真脚本以接口文档 + 替代实现方式开源

## 生成脚本

`scripts/` 下的 Python 脚本用于从原始仿真/数据库生成 Demo 所需静态数据（切片提取、差分可视化、知识库 JSON 导出）。均只读分析，不产生科学结论。
